隐私政策

更新于 2026年11月7日

本站收集哪些数据

本站是一个静态网站，不提供评论、登录或会员注册功能，因此不会主动收集访客的姓名、邮箱、IP 地址或其他个人身份信息。

本地存储

本站仅在浏览器本地保存一项偏好设置：浅色 / 深色主题的选择（localStorage 键名 theme）。该信息不会上传到服务器，清除浏览器数据即可移除。

托管与访问日志

本站通过 GitHub Pages 托管，页面与图片由 GitHub 的服务器提供。GitHub 可能按其隐私政策记录访问日志（例如 IP 地址、浏览器类型与访问时间），本站无法访问或控制这些日志。详见 GitHub 隐私声明。

外部链接与返佣链接

文章中的交易所、社群与工具链接可能包含返佣参数。点击这些链接后，你将离开本站并受目标网站自己的隐私政策与条款约束。本站无法控制第三方网站的数据处理行为。

图片资源

文章图片随站点一起托管，不依赖第三方图床，也不会通过图片请求向第三方传递访客信息。

政策更新

如本站功能发生变化（例如未来增加评论或邮件订阅），本政策会相应更新。最后更新日期：2026 年 11 月 7 日。

联系方式

如对隐私政策有疑问，可通过 Twitter / X 或 Telegram 联系作者。
