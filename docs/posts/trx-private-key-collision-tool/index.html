TRX私钥碰撞器说明

作者 hightbiger更新于 2025年3月30日

写在文章之前，私钥碰撞这事情本身是属于微乎其微的概率，但是确实周围有碰到的人，也是我写这个的初衷，你可以试着碰一碰，可是如果遇到碰到的是人家在使用的，千万别乱来，这属于违法行为，我们只动那些被丢失的钱包。而且数量其实不少

这个私钥破解器需要用的trx的官方api，https://tronscan.org/#/myaccount/apiKeys 这个是申请地址

进入申请地址注册后

点击添加一个apikey 复制好apikey给小助理给你们封装进去就行。 hightbiger 微信
