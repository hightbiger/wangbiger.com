五分钟学会利用电脑空闲时间免费薅一个赚上亿个比特币的机会----每秒五千次以上的比特币私钥暴力破解工具

作者 hightbiger更新于 2026年5月18日

我们需要的就只有一台平时办公用的电脑，本人亲测每秒是五千次以上的碰撞，相比于比特币矿机，这无疑是一个节约电费的方式，而且挖掘碰撞的是比特币拥有地址的地址池，个人是建议将收集来的地址进行一个分类，那些早期的死地址才是我们首要破解的目标，毕竟如果你破解到别人的私有地址将别人的钱转走其实并不是一件好事，而且太多的地址也会增加你程序的运行负担，早年的死地址里拥有大量沉淀的比特币，运气好中一个就能直接实现财富自由了。当然，这样的概率无异于购买彩票，所以我更愿意你们当作闲暇的时候的念想来做这件事情。言归正传，下面介绍下具体的步骤，视频版本请移步youtube进行观看

Btcbf是一个快速高效的比特币私钥暴力工具，用python编写。它的工作原理是生成随机或顺序私钥及其相应的公共地址。然后通过在线 API 或离线数据库检查地址。

使Btcbf快速的主要是位库。感谢它的开发者！

快速入门

 $ git clone https://github.com/vlnahp/Btcbf.git

 $ cd Btcbf

 $ pip install -r requirements.txt

新版本增加一个  pip install base58

 $ python Btcbf.py or  $ python3 Btcbf.py on Linux

要求
在脱机模式下，数据库是必需的。默认情况下，它包含一些地址。老实说，在线搜索需要很长时间，并且程序中包含的余额地址太稀缺（因为拥有包含所有地址的当前文本文件将使该存储库超过 5GB）。因此，希望的用户可以从此处下载最新的文本文件（直接链接），重命名并将其替换为“地址.txt”。但要小心内存问题。仅当您有足够的 RAM 时才使用此数据库！address.txt

要安装要求，请运行以下命令：

$ pip install -r requirements.txt

用法
只需执行以下命令：或者在Linux上，Btcbf会告诉您该怎么做！$ python Btcbf.py$ python3 Btcbf.py

键入所需的操作并按照说明进行操作。（我喜欢与我的程序互动🙂)

结果将保存到主目录中。foundkey.txt

PS：今天刚和一个群友聊天，说到这个软件的弊端，有条件的朋友可以自行优化修改： 就是一个私钥过去生成的是正常地址，现在的钱包一类的用的都是私钥生成压缩地址。软件本身随机生成私钥后据说生成的是压缩地址，所以早期的一些地址理论上是碰不到的。解决方案就是生成私钥以后计算两个地址，一个是压缩地址另一个是非压缩的正常地址，两个地址都拿到我们的地址池进行比对，这样才能解决这样的一个弊端，感谢fish的专研精神。有什么问题欢迎大家进行讨论。
